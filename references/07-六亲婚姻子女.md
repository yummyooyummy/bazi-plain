# 六亲、婚恋与子女：两套方法并列

先有03—04的全局结论，再解释六亲。下文“男/女”是在交代古书分类，不是对现实身份、伴侣性别或家庭分工的规范。只按本人自愿提供的关系目标讨论，不由排运算法参数擅自推知现实家庭。

## 一、固定十神法与用神法不能混算

| ID | 条件 → 输出 | 限制 | 出处 |
| --- | --- | --- | --- |
| Q07-01 十神角色 | 传统男命财作妻象、女命官杀作夫象，印为母象、财为父象；食伤作子女输出线，男命另有官杀为子说 → 列传统角色候选 | 所有十神名称来自程序；无该星不等于现实无人，多星不等于多个伴侣 | 《子平真诠·论宫分用神配六亲》；《滴天髓阐微·夫妻》《子女》《父母》原注与任注 |
| Q07-02 宫位 | 年月查家庭背景主题，日支作伴侣宫，时柱作子女/晚段主题 → 记被触动的位置 | 柱位是取象，不是现实人物证据；梁氏柱位年龄分段不当作交运年龄 | 《子平真诠·论宫分用神配六亲》；梁湘润P15—19方法归纳 |
| Q07-03 男命妻线 | 财星是否与已定喜用同路、能否通关、是否有根受护 → 有情/受阻的结构说明 | 财旺或坐妻宫不能单独推出婚姻好坏；不写伴侣品德、外貌、忠贞 | 《滴天髓阐微·夫妻》任注 |
| Q07-04 女命任法 | 在结构用神已经成立后，夫星按用神、子星按喜神另列 → 用神法角色 | 原文“凡女命之夫星，即是用神，女命之子星，即是喜神”；不把庚食神改名为正官 | 《滴天髓阐微·女命》任注 |
| Q07-05 子女异说 | 男命原注官杀为子、任氏重食伤又随用神；女命任法以喜神为子 → 至少列固定角色与结构角色两栏 | 两栏一致不是生育验证；不同也不是孩子有问题；禁止性别、数量、能力断语 | 《滴天髓阐微·子女》《女命》 |
| Q07-06 父母异说 | 原注认财父、印母；任氏批评财父同宗解释，重生我之神及年月喜忌 → 两法并列 | 不能只凭财弱就断父亲不利；出生家庭与经历只能来自本人自愿陈述 | 《滴天髓阐微·夫妻》《父母》 |
| Q07-07 时间未知 | 时柱未定或有边界备选 → 分盘检查；时柱相关子女、晚段内容暂缺 | 不用已知三柱补出时柱；同样不因不回答私事就计为支持 | 本skill R1、R4、R6；古法位置依据同Q07-02 |

本skill采用**固定十神保持名称、任法另列功能**的口径。理由：既能核对程序，又能呈现原书不拘一星的方法，避免一句话里“官既是夫、财又是夫”来回变。所有人格羞辱、生育或死亡断语不用，遵守R8、R9。

## 二、任氏女命替代规则怎么查

以下只在任氏方法栏使用，前提是强弱、喜用已按03—04独立完成；不能为了得到某种家庭结论临时改用神。逐项以实际力量而非字数认定旺弱。

| ID | 条件 → 任法结构角色 | 为什么用这条 | 出处 |
| --- | --- | --- | --- |
| Q07-08 | 官过旺，无比劫可担 → 印作夫星功能 | 印化官生身；先核印能否作用 | 《滴天髓阐微·女命》 |
| Q07-09 | 官过旺，有比劫但无印 → 食伤作夫星功能 | 查食伤能否制官而不反耗身过甚 | 同书《女命》 |
| Q07-10 | 官弱且伤官强 → 财作夫星功能 | 财能通食伤与官，须自身不被劫坏 | 同书《女命》 |
| Q07-11 | 比劫旺，无可用财官 → 食伤作夫星功能 | 泄比劫；若印又压食要另列失败条件 | 同书《女命》 |
| Q07-12 | 印满局，无可用官伤；或官轻印重 → 财作夫星功能 | 财抑印，需要身能任、财有根 | 同书《女命》 |
| Q07-13 | 伤官旺而身弱 → 印作夫星功能 | 制伤生身；财破印则原路受阻 | 同书《女命》 |
| Q07-14 | 身旺、食伤多 → 财作夫星功能；再找护持此路径的喜神作子星功能 | 食财连续不等于真的有伴侣孩子 | 同书《女命》 |

同盘多条似乎同时符合，先回查主路径及反证；不可择取最讨好的角色。古书未给出机械互斥顺序，本skill也不虚构统一排序，必要时保留任法内部两读。

## 四、古籍 worked examples

### 例一：夫星不必是官星，但十神不改名

《滴天髓阐微·女命》：**癸丑 庚申 戊午 己未**。

1. 戊日，庚食神、癸正财、己劫财；庚申有根，午未丑有印比支持。身有依托，以金泄、财润为连续路径。
2. 固定角色法：木官杀作夫象，原局仅未藏乙官，不能说全无夫星。金食伤作子女象。
3. 任法：庚食为关键出口，承担夫星功能；癸财承食并润土，承担子星喜神功能。它们仍叫食神、正财，不能改成官。
4. 原书记癸亥运“夫举于乡”：只作为该书在财润泄秀条件下的叙述，不是成婚年份，亦不复述孩子数量。
5. 申亥有害也要保留；原书仍叙此运顺，反证“一个害足以推翻全局”。不据此承诺任何现实婚育结果。

### 例二：印重取财的替代路线

同书《女命》：**戊寅 甲寅 丁未 辛丑**。

1. 丁日、寅月，甲正印透且两寅，印重；辛偏财透、丑藏辛，戊伤官与土支给财来源。
2. 固定法：水官杀作夫象（丑中癸仍在），土食伤作子女象；未丑冲如实保留。
3. 任氏原文“必以辛金為夫，丑土為子”：辛抑过重印为所用，丑土泄火生金为喜，按Q07-12另列功能角色。
4. 丑未冲不直接等于婚变；原著把它放在去比印、存财的结构语境。不能照搬为“凡冲配偶宫都对婚姻有利”。
5. 后运若土金有效，可能维持该路径；火木重来能否损财另查。不从这两个案例推广伴侣财富、身份或子女能力。
