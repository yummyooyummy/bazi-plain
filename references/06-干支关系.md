# 干支关系：先记结构，再判断作用

输入是程序 relations，必须保留位置（原局哪柱、哪步运、哪年）。计算表与命名以 scripts/relations.py、tables.json 为准。合冲并存不是程序矛盾；下面只分析作用，不删改结构事实。

## 一、查到关系后做什么

| ID/关系 | 条件 → 结论/操作 | 不能推出什么 | 出处 |
| --- | --- | --- | --- |
| Z06-01 干合 | 甲己、乙庚、丙辛、丁壬、戊癸查到 → 先列谁合谁，再查所合的是喜神、相神还是忌神 | 五合不等于化象；没有月令、根气、阻化检查，只可说合绊/合化候选 | 《子平真诠·论十干合而不合》；《滴天髓阐微·化象》《岁运》 |
| Z06-02 六合 | 子丑、寅亥、卯戌、辰酉、巳申、午未查到 → 列牵连及是否影响原有生克通道 | 六合不是必然有利；如喜水遇子丑，还须看土制水，不能只说合水更旺 | 《子平真诠·论刑冲会合解法》；《滴天髓阐微·岁运》 |
| Z06-03 六冲 | 子午、丑未、寅申、卯酉、辰戌、巳亥 → 查相邻/遥隔、双方根势及冲掉的是所用还是所忌 | 不按冲的数量判坏；也不因有两个同支就让冲自动作废 | 《滴天髓阐微·地支》《战局》；《子平真诠·论刑冲会合解法》 |
| Z06-04 刑 | 程序列子卯相刑、寅巳申/丑戌未两支刑或三刑齐、辰午酉亥自刑 → 分开记结构完整度，再查所触及的根和成格路径 | 两支刑不能写三刑齐；一辰不能自刑；不由刑推出犯法、家暴或伤病 | 《子平真诠·论刑冲会合解法》；本项目刑表工作定义（参《三命通会》刑论） |
| Z06-05 害、破 | 六害、六破由程序查出 → 作为次级关系，查是否实际阻断已经确认的喜用路径 | 不设“害必比合强”优先表；无作用链时只记关系，不添加事件 | 本项目查表工作定义；作用取舍归纳自《滴天髓阐微·地支》《岁运》，不是该书逐项六破断法 |
| Z06-06 三合 | 申子辰水、亥卯未木、寅午戌火、巳酉丑金三支齐 → 记三合结构，查透干、得时、冲破后才论势 | transformed=false仍是程序事实；结构齐不等于全部藏干永久消失 | 《滴天髓阐微·方局》；《子平真诠·论用神变化》 |
| Z06-07 三会 | 寅卯辰木、巳午未火、申酉戌金、亥子丑水齐 → 方势候选，同样检查时气与反神 | 会与合可同见，不以“有方就删局”处理 | 《滴天髓阐微·方局》《形象》 |
| Z06-08 半合 | 三合的两支**含中神子卯午酉** → 半合；如亥卯、卯未 | 邻接、有天干领出、有无中神受冲分别评；不是全三合 | 《滴天髓阐微·方局》；本项目将含中神两支统一命名半合 |
| Z06-09 拱 | 仅生墓两端，如亥未、巳丑，缺中神 → 拱合候选，列缺字 | 不把卯、酉当作原局已存在；后运补齐也仅在该运年重判，不改原局 | 《滴天髓阐微·方局》；本项目区分名称 |
| Z06-10 夹 | 同干、两支隔一位，程序列同干夹字候选 → 保留缺字及counts_as_present=false | 不补第五支，不用虚夹直接成立从格/调候/子女星 | 梁湘润《子平概论》P24方法归纳；本项目保守工作口径 |
| Z06-11 遥冲为动 | 原局年时等遥隔冲，作用路径没有紧贴直达 → 先标远端牵动，根是否受损另查 | 程序冲仍保留；“动”是解释强度，不等于搬家、离婚，也不能保证完全无影响 | 《滴天髓阐微·地支》遥隔论；梁湘润P27—32、王德峰冲合主题的方法归纳 |
| Z06-12 旬空 | 日旬空与各柱own_xunkong分列 → 以既定日旬表作统一参照，必要时另示自身旬空 | 不因空亡删除柱、根、合冲；不拿某柱自己的旬空偷换全局空亡表 | 本项目排盘口径；梁湘润、王德峰空亡主题方法归纳 |

本项目六害表：子未、丑午、寅巳、卯辰、申亥、酉戌；六破表：子酉、丑辰、寅亥、卯午、巳申、未戌。它们可能与六合等重叠，程序照列；解释不得只保留自己想用的一项。此为现有查表工作定义，非新增吉凶断法。

## 二、会合能否解冲：必须走完的判断链

| ID | 条件 → 判断 | 反证/仍需保留 | 出处 |
| --- | --- | --- | --- |
| Z06-13 | 冲的一端有实际六合/三合牵住，合神未被更强作用拆散，且所用根受护 → 可以列“有解冲路径” | 原冲事实不删；合神无根、遥隔受阻、被冲坏时只能列可能解 | 《子平真诠·论刑冲会合解法》 |
| Z06-14 | 合神再被别的会局拉走，原保护路径不成立 → 原冲重新成为主要检查项 | 不能口诀“有合不论冲”；同字参与多组关系需画位置链，不重复算成功救应 | 《子平真诠·论刑冲会合解法》子午、丑合及巳酉丑对照 |
| Z06-15 | 局的中神受有力紧冲，或两支半合被近冲破坏 → 标局势受损，回查格局和根气 | 遥冲、局外冲与紧贴冲不得等效；不存在统一“冲必胜合/合必胜冲” | 《滴天髓阐微·方局》《地支》 |
| Z06-16 | 两冲一、两刑一 → 所有实际关系都保留，再按位置、根势解释 | 沈氏部分例有数量解法，任氏《战局》反对机械二不冲一；本skill采用不按数量取消，因为事实可核且避免隐藏反证 | 《子平真诠·论刑冲会合解法》与《滴天髓阐微·战局》并读 |

## 四、古籍 worked examples

### 例一：同是土，冲到哪里才是关键

《滴天髓阐微·衰旺》：**戊辰 戊午 戊申 己未**。

1. 程序核申中庚食、壬财，辰有癸财、乙官，未有乙官丁印；事实不删，整体厚土夏令偏强。
2. 原著取金泄土。文献列壬戌运时，外来戌与年辰六冲，戌又藏丁印土根。
3. Z06-17—20：不能说财库被开就好；先查冲辰对藏水及土气的影响，戌燥土增火土是否阻金水出口。
4. 结论是本例壬戌运不能仅凭壬财透就判佳；与庚申、辛酉的金出口路径不同。原书负面叙述只保留结构含义，不转写伤亡预测。

### 例二：古书称会，不等于程序有全三合

《子平真诠·论建禄月劫》：**己未 己巳 丁未 辛丑**（已/己异文见04）。

1. 程序给巳丑拱合候选、缺酉，不是含中神半合，更不是三合；两个未分别与丑形成冲，全部列出。
2. 己食两透、辛财透且丑藏辛，可沿火→土→金找食财路径。
3. 沈氏称巳丑会、“化劫为财”，本skill保留为取用结构解释，不将程序改成已化金，也不凭它删除丑未冲。
4. 冲触丑财根、未火土根，其结果须结合食财流通；不能从丑未冲直接推出婚变，更不能二未便宣称不冲一丑。
5. 后来酉到只能说该时段三合结构补齐，仍查时气、透干及中神是否被冲，不追改原局。
