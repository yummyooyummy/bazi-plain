# 格局、病药扶抑、调候：分别完成三线

先完成[03](03-强弱与从格.md)。月令用神是取格枢纽；扶抑用神是缓解结构偏向的因素；调候用神是传统寒暖燥湿需求。输出时带前缀，不偷换三种“用神”。

| ID | 条件 → 结论/下一步 | 限制与反证 | 出处 |
| --- | --- | --- | --- |
| G04-01 | 月令本气透干 → 先按本气十神取格 | 日干自身不算另一个透用神；查比劫、阳刃入口及会合变化 | 《子平真诠·论用神》《论用神变化》 |
| G04-02 | 本气不透，中、余气有透 → 取所透十神候选 | 两气都透先分别列，不默选更好听的一格 | 《子平真诠·论用神变化》《论杂气如何取用》 |
| G04-03 | 多气兼透 → 看纯杂、有情、位置；相成可兼用，相战查成败 | 本气优先是入手顺序，不是免查全局；财印同透不必相伤 | 《子平真诠·论用神纯杂》《论用神格局高低》《论杂气如何取用》 |
| G04-04 | 无可用透气、无成立会支变化 → 留月令本气初步取格，注明藏而未透 | 不找时柱最旺字冒充月令已透；查根、位置、成败再定路线 | 《子平真诠·论用神》《论用神变化》；本skill操作整理 |

| G04-06 | 月令属原书阳刃 → 看官杀制刃及财印配置 | 戊午是原书刃例，不能因午本丁是印漏掉；阴干刃各家不同，不暗改脚本 | 《子平真诠·论阳刃》《论阳刃取运》；《滴天髓阐微·地位》 |

| G04-10 | 会合前后取格不同 → 分列原格、变化条件、保留或退出理由 | 丙寅会午戌，甲仍透时原书可留印格；不能删掉所有原透干 | 《子平真诠·论用神变化》 |

## 二、顺逆、相神、成败救应

顺逆是结构处理，不是善恶人格。每条“成”还须身能任、根透落实、实际不受阻。

| ID/格 | 条件 → 成路 | 败因 → 查救应 | 出处 |
| --- | --- | --- | --- |
| G04-11 财顺用 | 食生财、或财生清官护财，身能任 → 留财与生护链 | 比劫夺财 → 食伤化劫/官制劫；财露杀 → 制合杀而存财 | 《子平真诠·论财》《论用神成败救应》 |
| G04-12 官顺用 | 官清有财生/印护，身可承 → 留官及财印 | 伤克、杀混、官合去、根冲坏 → 印制伤、合制杀取清、有效会合护根 | 《子平真诠·论正官》《论用神成败救应》 |
| G04-13 印顺用 | 印轻官杀生；身印两旺食伤泄秀；印重适量财抑 → 分别取路 | 印轻财重破印，身印重再杀生印壅塞 → 比劫护印/合财/保泄秀出口，不能混用 | 《子平真诠·论印绶》《论用神成败救应》 |
| G04-14 食顺用 | 食生财；或身强食制杀、无财转生杀 → 留食生制功能 | 枭夺食、财转生杀、印夺食护杀 → 财护食制枭；或另转弃食就杀透印，不能两路同报 | 《子平真诠·论食神》《论用神成败救应》 |
| G04-15 杀逆用 | 身有依托，食制杀或印化杀且路线清 → 制化杀 | 财助杀无制、印夺制杀之食 → 食制/财去印存食；若走印化杀反忌财破印 | 《子平真诠·论偏官》《论用神成败救应》 |
| G04-16 伤逆用 | 伤生财；身弱伤旺有根印制伤；或伤杀相配无财助杀 → 各循成路 | 伤见官、佩印却伤轻身旺、财再生杀 → 印/通关/合杀；金水气候例不能机械同论 | 《子平真诠·论伤官》《论用神配气候得失》 |
| G04-17 枭逆用 | **食格以食为出口**而偏印有力截食 → 制枭保食 | 若月令印格、身印两旺、透食泄秀，不套本行 | 《子平真诠·论用神》《论食神》《论印绶》 |
| G04-18 刃逆用 | 刃旺有官杀制衡，财印不妨制衡 → 刃用官杀 | 食伤打掉所用官杀 → 查印护；无官杀不能叫杀刃相济；化印另查09 | 《子平真诠·论阳刃》《论用神成败救应》 |
| G04-19 相神 | 少了某字，当前成路便断 → 该字为相神 | 官赖财生财为相；杀赖食制食为相；不是第二喜欢的五行 | 《子平真诠·论相神紧要》 |
| G04-20 救应复核 | 败因确被制、合、通关或护根处理，救神有力未损 → 败有救 | 救神又被克，不能只报成功；原局没有、要等运助才有则注明条件 | 《子平真诠·论用神因成得败因败得成》《论用神成败救应》 |

**偏印透食的防误判**：《论用神》反对一见偏印透食就叫枭夺食。先辨月令用谁：印格且身印两旺，食能泄秀，按G04-13；食格的食实际被枭截断才按G04-17。杀印相生也同理：印格可成，食制杀格却可能夺食护杀。

## 三、三线各自得出什么

| ID/线 | 顺序 → 输出 | 冲突处理 | 出处 |
| --- | --- | --- | --- |
| G04-21 格局 | 月令 → 成路 → 败因 → 原局救/须运救 → 取格用神、相神、待保护环节 | 不因身强喜克而毁掉相神 | 《子平真诠·论用神》《论相神紧要》《论用神成败救应》 |
| G04-22 病药扶抑 | 03结论 → 找偏盛、受制、过泄、堵塞 → 比较扶制泄通关是否有依托 → 主需求与条件 | 旺太过弱官不能制，先查泄；失令有强根不机械加印 | 《滴天髓阐微·衰旺》《源流》《通关》《疾病》；王德峰病药方法归纳 |
| G04-23 调候 | 日干+节令月支查[05固定表](05-调候表.md) → 保留先后条件 → 对照有无、根气、能否作用 | 缺某调候神不等于见它即好；不是公历月份查表 | 《穷通宝鉴·五行总论》及各十干月篇；《子平真诠·论用神配气候得失》 |
| G04-24 优先级 | 已确认从格先顺其势；正格以格局成败和全局承受力为主，调候分列 | 调候成急务时写明它如何恢复成格功能，不能凭气候第一跳步；从格仍须审泄秀与反神 | 《滴天髓阐微·从象》《形象》；《子平真诠·论用神配气候得失》；既定skill口径 |
| G04-25 交付 | 三线逐一列支持、反证、依赖条件；同向较高、部分冲突中、全冲突低并列两案 | 指方法一致性，不是现实命中率；两案倾向只能由计分脚本给 | 《子平真诠·论用神配气候得失》；本skill R6、R7 |

**各家取舍**：梁湘润多入口取格（含时柱、同类多见、混合、会局）作旁证；本次用户明确要求下，主线采用沈氏月令法，会合后按具体十神顺逆。课程“会局一律逆用”保留为异说，不作主规则，避免未说明就从月令官格跳到时柱财格。梁、王病药与运年仍分别使用，仅写方法归纳。

## 四、古籍 worked examples

### 例一：月劫别取食财

《子平真诠·论建禄月劫》：**己未 己巳 丁未 辛丑**。电子本“已巳”不合法，按既定规范作己巳，保留异文说明，不改原文档。

1. 丁日巳月，丙为劫财，先走G04-05；不能见己透直接称月令食神格。
2. 两己食透、未丑为土依托，辛偏财透、丑藏辛，食→财有承接；火根与泄耗两端都保留。
3. 巳丑缺酉，程序是拱合候选；原书称化劫为财，保留在取用语境，不报已经三合化金，详06。
4. 格局线：月劫别用财，食化劫生财，辛所用、己为成路相神。扶抑线：偏强已有泄财出口，保土金流通。调候线：丁**巳月**查05，季节需求另列，不能删除食财链。
5. 后运若印夺食或劫直接争财，查是否实际成阻及有无救应；无起运资料不编年份。

### 例二：印用食不是自动夺食

《子平真诠·论印绶》：**戊戌 乙卯 丙午 乙亥**。

1. 丙日，卯本乙正印透月时，取印格。丙午火根，身印均有依托。
2. 戊食透年、戌土为根，按G04-13身印两旺取食泄秀；不因印食同盘判夺食。
3. 格局线护食泄秀，扶抑线不无限加印；调候按丙卯对应格保留壬（无壬姑用己）的需求及实施条件，不替代印格主路。
4. 财到来要查抑过旺印还是反泄食、破结构，不能一概“印格忌财”或“财总救食”。

### 例三：润下不能抄成一律忌火

《滴天髓阐微·形象》：**壬子 辛亥 癸丑 壬子**。亥子丑、壬癸辛，原著润下先走03独象。木泄水与原甲寅、乙卯描述同向；冬水调候需求另列，但原评认为本例未形成有效食伤泄化，火财到来缺有效木通关，原文丙辰段不利。条件项须写：`原局无食伤（评测标签，指未形成有效食伤泄化） → 火财直入缺有效通关 → 本例不利`。已有木时另判，不推广到所有润下。

**润下例的文字校核**：程序亥中确有甲伤官；原书原句是“原局無食傷之化”，不是全无食伤字。本文件“无食伤”的简称只用于指代原评的泄化条件，不得删掉甲、不得当作无藏干事实。用户已确认保留评测标签“原局无食伤”，并补清其含义为“未形成有效食伤泄化”；标签值、程序及测试保持不变。藏甲何时足以形成有效泄化，原书没有统一阈值，新盘仍须保留疑点。
