# 健康：传统对应、日常关注与一般体检提醒

R9是硬边界：不诊断，不预测死亡、重病、事故。下面先说明古籍怎样组织五行偏枯，再严格限制个人报告能说什么。传统五行对应不证明实际脏器功能、体质或疾病风险；不能因加上“可能”就输出病名。

## 一、传统对应表与可输出边界

《滴天髓阐微·疾病》任注以阴干为脏、阳干为腑；以下用于说明传统对应，可在报告中写成日常关注方向，必须紧邻注明“不是诊断”；不是医学检查表，也不代表哪个器官存在问题。

| 五行 | 传统五脏对应 | 天干传统细分 | 个人报告可用的一般保养话题 |
| --- | --- | --- | --- |
| 木 | 肝 | 甲胆、乙肝 | 作息、活动与休息的安排；不说肝胆有病 |
| 火 | 心 | 丙小肠、丁心 | 日常节奏、休息；不推心脏风险 |
| 土 | 脾 | 戊胃、己脾 | 饮食规律；不判脾胃功能或要求忌口 |
| 金 | 肺 | 庚大肠、辛肺 | 居住环境与通常生活习惯；不判呼吸系统疾病 |
| 水 | 肾 | 壬膀胱、癸肾 | 规律休息、一般生活安排；不推肾功能、生殖或生育问题 |

右栏只是可选择的普通生活话题，不是按五行生成的器官保养处方。报告允许写：“传统五行中，××对应××，可作日常关注方向；这不是诊断，不代表该器官存在问题。”不得续写病名、风险高低、功能强弱、真实体质、寿命或治疗。五行旺弱不能证明对应器官需要额外检查。

### 统一报告写法（与12保持一致）

1. **传统对应与关注方向**：“传统五行中，××对应××，可作日常关注方向；这不是诊断，不代表该器官存在问题。”可以附规律作息、饮食和适量活动等一般生活提醒，不写身体风险。
2. **一般体检提醒（可选）**：必须另起一段，开头写“**一般常识，非八字推导**”。仅依据本人已确认年龄、所在地区的现行一般体检安排给提示；不依据五行决定项目和频率。
3. 年龄未知、只有古籍四柱时，省略年龄分段，不倒推年龄、不为了加这一段索要生日。若年龄已有可信确认，只传已确认年龄或年龄段，不重复传生日。
4. 体检提醒只说了解适龄常规安排、保留并对照以往体检记录、具体项目周期由合格医疗机构结合实际情况确定；不写病名、个体风险判断、诊断、寿命、治疗，不开清单替代医学建议。

| ID | 已确认条件 → 允许的体检提醒 | 限制与依据 |
| --- | --- | --- |
| B10-08 | 已确认未成年 → 可提醒由监护人了解当地适龄常规保健、学校体检安排 | 一般常识，非八字推导；不凭五行增减项目，不自定周期 |

## 二、从偏枯到保养方向的判断表

| ID | 条件 → 古籍内部判断 | 现代报告怎样写 | 出处 |
| --- | --- | --- | --- |
| B10-01 | 生克有情、所用有根，偏向有出口 → 古书所谓和，不要求五行齐全 | 可讲结构较流通；不能承诺身体健康或一世无灾 | 《滴天髓阐微·疾病》原注及任注 |
| B10-02 | 旺但未过度，制神有根可任 → 古法可制；旺极而制神弱 → 先查泄旺 | 只解释结构的“制/泄”，不写医疗上的清热、攻补、疏肝等干预 | 同书《疾病》《衰旺》 |
| B10-03 | 弱神有根且能受生 → 扶持路线；无根不能受生 → 不机械增扶 | 不按缺五行补器官，也不说弱金就是肺弱 | 同书《疾病》；《穷通宝鉴·五行总论》 |
| B10-04 | 火土偏燥、缺有效润泄 → 传统燥象；水势寒湿、缺有效暖泄 → 传统寒湿象 | 仅写“在传统取象里偏燥/寒，保养提醒限一般生活规律”；不认定实人体质 | 《滴天髓阐微·寒暖》《燥湿》《疾病》；《穷通宝鉴·论土》《论水》 |
| B10-05 | 有一行少、缺，但主结构不需要它 → 不为凑齐而补 | 可说明五行缺不等于器官缺陷；不卖改运补五行方案 | 《滴天髓阐微·疾病》“全者宜全，缺者宜缺”的语境；《形象》 |
| B10-06 | 运年损结构出口、偏枯加重 → 方法内重检喜忌 | 不转换成某年生病、手术、事故，也不拿健康经历给读法加分 | 《滴天髓阐微·疾病》《岁运》；本skill R9 |
| B10-07 | 用户主动提真实症状/诊断 → 八字部分停止医学推断，按真实需求另处理 | 不以命盘替代诊疗，不要求隐私病史作校准；本参考不提供医疗判断 | 本skill R9；不是古籍治疗规则 |

古籍短引（均为《滴天髓阐微·疾病》）：“其要貴在泄其旺神，瀉其有餘”；“旺神太過者宜泄，不太過宜克”。这两句用于结构制泄的比较，不是临床治疗原则。该篇还有“五行和者，一世無災”等绝对断语，本skill只解释其历史用法，不把它作为健康保证。疾病篇旧式病名、寿命、夭亡与把病转嫁六亲的说法均不迁入个人报告。

**争议取舍**：原书把五行偏枯直接连到疾病，也有同结构转应财耗、亲属的叙法。本skill不采用这种可任意换结果的验证方式，原因是它不能从命盘核实真实健康。保留五脏词典和制泄方法供古籍研究；对人只给一般保养方向，不创造新的疾病风险表。

## 三、古籍 worked examples

### 例一：不是所有旺都只能泄

《滴天髓阐微·疾病》：**癸未 甲寅 戊戌 庚申**。

1. 程序核戊日，甲杀在寅有根，庚食在申有根；戌土给日主依托，癸财透。
2. 春木当权，但不是无制的孤旺；原著强调庚得禄能制木，属“不太过宜克”的结构例。寅申冲、未戌刑关系仍保留，不能因此一律取消庚根。
3. 按B10-02逐项说明制神有依托，制与泄不是照某五行数量选。这里只复现该书论证，不抄其长寿、无灾结论。
4. 健康输出：“本例可用于学习木土金之间的制衡；无法由此判断当事人身体。保养只谈规律作息、饮食和适量活动。”不会写肝克脾、胃病等推断。

### 例二：旺土的出口不能被忽略

同篇：**己巳 辛未 戊戌 己未**。

1. 戊生未，未戌与己土支持厚，巳火又生土；辛伤官透，戌藏辛，金是现有泄土出口。
2. 原著以辛为精华，丁卯运丁克辛、木火助燥，对出口形成阻碍。只复现丁为戊印、辛为戊伤官的程序事实及生克路径，不转述原病死叙事。
3. B10-02、04提示区分“旺太过需泄”和“火更多就是生身有益”；不可将用神模型当服药补泻依据。
4. 健康输出限一般饮食规律、休息与活动，不说脾虚、血病、未来某运有病，可在年龄已确认时另附一般体检提醒，标明“一般常识，非八字推导”；本古例年龄未知，省略该段。
