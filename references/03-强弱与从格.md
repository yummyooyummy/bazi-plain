# 强弱与从格：逐项判断

先用程序事实填写得令、得地、得势，再筛从格，最后谈喜忌。不设五行数字权重。规则ID供分析卡引用，不是倾向计分。

## 输入与输出

只读 facts.pillars、pattern_observations、relations。藏干存在、十神、十二长生是程序事实；是否得力是方法判断。输出：**偏强 / 中和 / 偏弱 + 从格候选**。证据抵触而不足时写“偏强/偏弱待分”，不把拿不准当中和。每候选列满足、不满足、未定、出处；硬条件不满足先淘汰，不能计分救回。

## 一、强弱检查表

季节查表依《子平真诠·论阴阳生克》《滴天髓阐微·月令》《衰旺》的五行时气关系整理，只说明时气，不等于全局强弱。

| 时气背景 | 旺 → 相 → 休 → 囚 → 死 |
| --- | --- |
| 春寅卯及辰的春余气 | 木 → 火 → 水 → 金 → 土 |
| 夏巳午及未的夏余气 | 火 → 土 → 木 → 水 → 金 |
| 秋申酉及戌的秋余气 | 金 → 水 → 土 → 火 → 木 |
| 冬亥子及丑的冬余气 | 水 → 木 → 金 → 土 → 火 |
| 辰戌丑未的土本气另检 | 土 → 金 → 火 → 木 → 水 |

四土月同时记录土本气、春余/夏燥/秋燥/冬寒背景，不能两次累计得令。没有司令资料不断某藏干在当日独占月权。“死”是时气术语，不是人的生死。

**实根与十二长生分开**：如程序乙在午标长生，不得据此增加午中不存在的木根。《子平真诠·论阴阳生死》与任氏《天干》《岁运》对阴干长生有异说；保留程序查表，实根仍按藏干，不暗改任何一方。

| S03-16 从气 | 木火或金水等连续气势为主，弱异党无根受制 → 记录任氏从气解释 | 两种五行出现不能直接叫从气；无可比古例停在候选 | 《滴天髓阐微·从象》《形象》 |

**原注与任氏分歧**：原注真从要绝无生扶；任氏却将乙未日有微根、或带受制庚印的例列为从财。本skill不删事实：严格原注不成立；有明确受制路径则可列任氏从财/假从候选。新盘不能只说“弱根当没有”。从强的明文硬标准仍单列，不借从财例随意放宽。

**化象分歧**：原注重季令与辰；任氏反对机械逢龙而化，且收“乙丑 甲申 甲辰 己巳”为甲己真化。采用任氏全局法作候选、严格季令法作反证，不另造“甲己非四土月绝不化”的硬表。阻化因素未核清时不宣布真化。脚本 transformed=false 不得改写成程序已认合化。

### 从势、假从与化象的细化分支

以下每行均在前表候选条件成立后执行，不反过来拿一个喜运条件证明原局必从。

| ID | 已查条件 → 下一步 | 退出/反证 | 出处 |
| --- | --- | --- | --- |
| S03-22 | 从势且财官食伤一端独旺 → 以该端为主；三者均停 → 优先查财能否承食生官 | 财无根或被比劫破坏，不能声称已经通关；扶身根一旦成立重判 | 《滴天髓阐微·从象》 |
| S03-23 | 假从财，浅比劫争财 → 查官杀能否制比、食伤能否化比生财；暗印为阻 → 查财能否制印 | 制化之神也无根或被克，只能记救应未成；不一律见官就喜 | 《滴天髓阐微·假从》 |
| S03-24 | 假从官杀，比劫为阻 → 查官制比；食伤制官为阻 → 查财通关；印泄官扶身为阻 → 查财制印 | 财若反被劫坏、食仍有力制官，不可宣告抑假扶真成功 | 同书《假从》 |
| S03-25 | 日干相合对象单一、相邻，化神得季令/局势支持，原日干无可用独立根扶 → 进入化象复核 | 距离远、有效争合、根扶仍足、化神被有力克泄至不能成势 → 合绊或假化，不下真化 | 同书《化象》《假化》；争合只用于未真化时，不倒用于原书已认真化例 |
| S03-26 | 化神有余且有可靠泄神 → 泄化神；化神不足且生神能到 → 生助化神 | 化土过燥时再火土不是当然有利；阴寒化土与燥土不可同表 | 同书《化象》 |

化象五合的查法（依据《滴天髓阐微·化象》原注；只是**严格季令入口**，不是见合便化）：

| 相合及化神 | 原注季令入口 → 复核要求 | 任氏反证与采用方式 |
| --- | --- | --- |
| 甲己化土 | 四季土月 → 查土势、日干独立根扶、金泄水润 | 任例甲申月也认真化；严格法不满足时列异说，不删原例 |
| 乙庚化金 | 秋月 → 查金势、火克、土生、水泄 | 仅两干相合不够；以有无有效对抗力保留候选 |
| 丙辛化水 | 冬月 → 查水势、土克、金生、木泄 | 火若有强根保持原性，不机械说化水 |
| 丁壬化木 | 春月 → 查木势、金克、水生、火泄 | 水木过盛与木待火泄是不同条件 |
| 戊癸化火 | 夏月 → 查火势、水克、木生、土泄 | 冬水旺的戊癸合不能直接按化火解释 |

## 三、五种一行得气

共同条件：日干属该五行，方或局形成主势，得时得生，反向克神不能独立对抗。以下均据《滴天髓阐微·形象》《方局》；“破格”只说模型结构，不代表现实灾祸。

| ID/名称 | 条件 → 候选 | 破格及重检 |
| --- | --- | --- |
| S03-17 曲直 | 甲乙日，寅卯辰方或亥卯未局，木势得时，无有效金克 → 曲直 | 金得根制木；已有火出口时水再克火，不能一概喜水 |
| S03-18 炎上 | 丙丁日，巳午未方或寅午戌局，木火顺势，无有效水逆制 → 炎上 | 水得根冲克；金财须土食伤接引，不能一概金喜 |
| S03-19 稼穑 | 戊己日，土势专旺；理论条文四库全、不杂木 → 严格稼穑候选 | 木得根强克、土不成势；任氏另有未集四库的例，需标实例口径，不能私删严格条件 |
| S03-20 从革 | 庚辛日，申酉戌方或巳酉丑局，金势得时，无有效火逆制 → 从革 | 火有根制金；无水泄秀不能视作已经流通 |
| S03-21 润下 | 壬癸日，亥子丑方或申子辰局，水势得时，无有效土逆制 → 润下 | 土得势挡水；无木食伤时见火财查群比争财，有木时另论 |

《形象》润下例丑中藏己，作者仍认润下；故专旺采用有效反神标准，不以“藏一字即破”。这不修改从强的“绝无财官气”。失时而得局只列待定，再查岁运扶势，不自动给真格。藏支有根但全局受制的问题没有统一量化阈值，必须把作用路径写出来。

## 四、古籍 worked examples

### 例一：从强与有出口的对照

《滴天髓阐微·从象》：**丙午 甲午 丙午 甲午**。

1. 程序核丙日，午藏丁己，甲为偏印；夏火得令，四午实际火根，印比显著，S03-01—04支持偏强。
2. 明暗无金财水官杀，满足S03-09关键排除条件。藏己是伤官，不是食神透出且有依托的泄秀主路，不能因此否定作者标签。
3. 原书认从强：先顺印比，再审岁运异党是否取得对抗力，不复述伤亡断语。

对读《方局》：**甲寅 丁卯 乙未 丁亥**。

1. 乙得卯令，亥卯未全且寅助，仍为强木。
2. 两丁食神透，未藏丁有依托，泄秀有实际出口。
3. 原文“取丁火食神秀氣，非前造從強論也。”故退出一味印比从强，转木火泄秀；水生木同时可能克丁，不能一概说水喜。
4. 这个对照检查有没有有效出口，不是“见任一食伤就否定全部从旺”。

### 例二：有印比却是假从

《滴天髓阐微·假从》：**丁丑 壬寅 丙申 壬辰**。

1. 丙在寅有印、有藏根，丁劫透，不能写全无印比；壬杀两透，申中壬庚给杀及财源。
2. 寅申月日紧冲；原著据此认为寅根受拔、丁不能独立扶身，定假从杀用财。
3. S03-14保留原书假从；严格原注法因有印比不作真从。不能扩大成所有寅申冲都把寅完全删除。
4. 新盘根是否受尽未定时，同列从杀与偏弱需扶，依R6确认；古例标签不代表现实验证。

### 例三：从杀何时必须退出

《滴天髓阐微·从象》：**辛巳 辛丑 乙酉 乙酉**。乙无木根；巳酉丑齐、辛杀两透，乙比也无根，丑中癸偏印仍存在，不能说全无生扶字；原书据金势判从杀，印能否独立仅是任法个例取舍而非已建立通用阈值 → S03-12候选。原书乙未运“木得蟠根”：未带乙根又冲丑，破坏无可用根、金势稳定两个前提 → 当运重判。仅复现结构，不转述死亡结论。
