# 倾向计分与二次确认

用户已确认：以模板闸门表为准，60%并不属于“必须先问”区间；原示例的这句话不再沿用。R1—R10不改。

## 先登记证据，再问问题

每个候选用普通名字，如“顺势型”“需要扶持型”。每个事实和出处有ID；相同依据换一种说法仍只能用原ID，不能再加一次。模型不能先看用户的回答，再改那一年的预期。

计分输入只有两种候选；日期不需要输入计分器。类别及分值：hard_condition完全满足硬条件每候选一次20；classical_case每例10、该类净影响限制±20；line每条5，格局、旺衰、调候各一次；doubt每个独立疑点向50拉回10、不越过50；history每个已确认事件15，支持A加、支持B减，中性不动，净影响限制±45。按此顺序运行，最后限制5—95。该去重、顺序和上限口径已由用户确认。

假设性计分例：50→硬条件70→一个疑点60→两个合成支持事件90。这里不是任何真实命例，不含真实年份。

```json
{"candidates":["顺势型","需要扶持型"],"evidence":[{"id":"condition_1","category":"hard_condition","side":"A","source":"古籍篇章与事实ID"},{"id":"uncertainty_1","category":"doubt","source":"藏干是否起作用仍有争议"}]}
```

运行：`python scripts/score.py --input /outside/project/analysis-evidence.json`。不要用本页JSON说明里的占位出处冒充已核对来源。计分器只能固定账本，不能证明模型所填证据是真的；证据仍需核对。

## 闸门

- 主倾向<60：初判卡＋确认问题，不提前写细运。
- 60—79：可完整报告，反向部分并列，开头说明仍待核对。
- ≥80：完整报告，末尾附验证问题。
- 未定月柱优先停止完整报告；晚子日界口径未校准时先给双盘初判与问题；时辰未确认时，省略时柱依赖内容。
- 已先问而用户拒答：记questions_offered和user_declined_questions，允许倾向层面的条件性报告，受影响结论标待确认；拒答不加分，月柱硬闸门保留。

分值是人为约定的倾向点数，不是事件发生率或经过验证的可信概率。低于95仍有另一候选；95也不是确定无疑。

## 问题卡

一次最多5问，按区分力排序。每题先在本地记录：选择哪个年份或阶段、A/B各有什么相反预期、答案支持哪一方。向用户只给中性问题和“很顺／一般／很不顺／记不清”等选项，允许跳过。

可问某年整体变化、两个阶段哪个顺、出生记录是证明还是家人估计。不要问诊断、创伤、收入数字或感情私密细节。不要在题干里暗示“这个年份按我的判断应该很不顺”。

回答后只更新相关证据ID，展示分值变化和原因，同时记录不支持本候选的回答。最多三件净支持事件的分量不意味着可以从多件事件中只挑最支持的三件。

回测分两类：用于挑读法的旧经历属于校准数据；另存之后才核对的事件作为留出观察，不拿同一组资料声称既选中了读法又验证了准确率。

## 晚子两口径：先区分日柱，再谈本盘读法

读取程序must_confirm_zi_method与day_convention_comparison。默认split仅是展示顺序；只要真太阳时落在23:00—24:00，开头同时列split与23点换日的日柱、四柱。不要用单盘的80%读法倾向说另一种日界已经不存在，两者不是同一层比较。

每个口径分别完成强弱、从格、三线与运年；先登记两盘在性格行为及已知经历上哪些结论确有不同。每次最多5题，至少包含以下两类：

| 类型 | 如何形成中性问题 | 如何使用答案 |
| --- | --- | --- |
| 性格行为 | 从两盘实际不同的行为候选设计，例如处理同一类任务时常先做哪一步；给两种具体行为及“看情况/都像/都不像/说不清” | 只作辅助核对，不当成现实事件加15分，不把笼统认同当选盘证明 |
| 已知经历 | 选择程序能支持、两盘预期不同的年份/阶段，问学习、工作、搬家等非敏感变化；给顺/一般/不顺/记不清或中性事件选项 | 只将本人明确确认的独立事实按既定history口径计入；同一事件不重复计分，反例同样保留 |
| 出生记录（补充） | 钟表时间来自记录还是家人估计、是否可能跨时辰 | 区分时间误差与日界流派分歧；记录精确也不能自动证明哪个口径唯一正确 |

题目预期先留在本地：题目ID、口径/读法A与B预期、对应事实ID、原规则ID、何种回答是支持/反证/中性。不得先看答案再改预期；“已知经历”不等于可以从真实参考成品复制另一个人的生活事件。

未核对前先给两盘初判及问题，不写一个默认盘的确定人生表。回答后仍保留两种口径及反证，更新的倾向是传统模型内拟合，不是历法科学证明。用户不答时只写条件性并列，不能静默选盘；未定月柱硬闸门仍保留。

## 文字展示

把握统一写“把握：高 / 中 / 低”，运势写“好 / 一般 / 要注意”；百分比用文字或表格，不再配圆点、颜色、表情或图条。提问卡用普通文字选项，专业账本收进折叠附录。
