# 大运流年：先评价作用，再定位主题

先完成03—04，锁定所用、所忌及条件，不为解释某年经历临时改喜忌。只读程序 luck、annual、luck_segments；古籍自带运年作为文献输入，程序只核十神与关系，不反推生日和交运年代。

**争议取舍**：采用任氏十年整柱、支重干辅；流年干重而不删支。保留某些旧说前后五年法作异说，不采用，因为会忽略整柱相载。王的两问用来组织输出，梁的新旧事用来标注作用来源，均不替代古籍喜忌判据。

每行报告至少写：程序时段ID → 当前读法主需求 → 干支作用 → 原局/年运关系 → 支持及反证 → 宽主题 → 把握。事实【高】，方法推导【中】，现实事件取象【低】；没有现实资料不编职位、财富、伴侣身份。

## 三、古籍 worked examples：同一岁克运为何反向

### 例一：庚是所需，丙克庚使路径受损

《滴天髓阐微·岁运》：**辛卯 甲午 丙辰 庚寅**，文献运序列庚寅，叙事记“庚运、丙寅年”。

1. 程序核丙日，庚偏财，辛正财，甲偏印；午令火旺，寅卯木助火，庚坐寅无实际金根。
2. 原著把庚金作为所用。文献完整运序列有庚寅，可核整柱；庚在寅无金根，按Y08-04记截脚，不能只读庚而忽略寅。
3. 丙寅年输入程序：丙比肩增加木火助势，丙克庚财；Y08-08说明受损的是本例所用，非因为“岁克运”四字天然不好。
4. 两问：结构上财出口受阻；主题最多可讨论资源安排、产出兑现，不复述原书重病死亡，也不编现代破财事件。

### 例二：庚是所忌，同一个丙反而制忌

同书《岁运》：**辛卯 甲午 乙卯 乙酉**，也记庚运、丙寅年。

1. 乙日虽两卯根，但卯酉紧冲、夏火泄气、无水，不能据两根就判强；甲劫、乙比，午藏丁食，原著按伤官用劫。庚为正官，不是前例的偏财，原著不喜金。
2. 丙是伤官，丙克庚仍为“岁克运”，但此处削的是所忌金，原书记该年入泮。
3. Y08-08先定庚/丙角色再评价，不能把两例套同一吉凶。酉卯冲仍保留，不因原书叙顺就删冲。
4. 传统主题可以是学习评价中的发挥条件，不能从“入泮”转写成现代必考公成功。古书已知叙事不是独立盲测。

两例均缺出生日期与可核交运时刻，只做文献运干/年柱作用研究，不输出公历年龄。事实包录文献运序已给的庚寅及流年丙寅，仅核关系，不计算交运时刻。
