# 合盘：结构对照与条件性互动

v0.1 synastry.py 只验证两盘关系和互为十神，不给合婚分、适婚结论或现实关系预测。本文件把可讨论的条件写清，**不将说明文升级为已验证的专门合婚模型**。双方先各自完成03—08，边界盘未确认不偷偷只选有利一盘。

## 一、逐项判断表

| ID | 条件 → 可得结论 | 反证及边界 | 出处/性质 |
| --- | --- | --- | --- |
| H09-01 | 双方已有程序事实包且无未定边界 → 运行compare，保留跨盘关系位置 | 自己各盘关系与跨盘关系分开；资料缺失先补，不凭截图心算 | 本skill R1、R4；计算口径见06 |
| H09-02 干合 | 跨盘有五合 → 列A哪干合B哪干、对各自是什么十神；可作互动牵连的传统取象 | 跨盘五合不等于任何人的原局已化，不代表爱慕、忠诚或必结婚 | 《子平真诠·论十干合而不合》；《滴天髓阐微·化象》；跨盘应用为本skill教学归纳 |
| H09-03 支关系 | 跨盘合冲刑害破、三合三会 → 列双方位置，分别回查是否触各自所用/所忌 | 凑两盘成三合不能删除个人原局反证；关系多不等于好坏分 | 《滴天髓阐微·方局》《地支》；06工作定义；跨盘为归纳 |
| H09-04 互为十神 | 用程序双方日干相对十神 → 两个方向分别描述功能，如A看B为财、B看A为官 | 不是现实谁控制谁、谁养谁；不能把十神当相处习惯或人格测验 | 《子平真诠·论十干十二支》十神关系；本skill跨盘取象归纳 |
| H09-05 调候互补 | A确有某季节需求，B盘该元素有作用条件，且不损各自主路线 → 只能说象征上可作差异互补话题 | 一寒一热、缺啥遇谁都不足；B的五行不会物理进入A命局，更不证明能改命 | 《穷通宝鉴·五行总论》及日干月篇；《子平真诠·论用神配气候得失》；跨盘为教学扩展 |
| H09-06 天克地冲 | 程序列双方日柱干相克且支相冲 → 明列两个关系，作为差异/牵动较显的传统取象 | 不写必离婚、相克伤害、出轨或劝分；不是双方现实有冲突的证据 | 《滴天髓阐微·岁运》的同柱冲克讨论；本项目反吟候选工作定义，跨盘解释未验证 |
| H09-07 单向得失 | 同一跨盘关系对A是所需、对B是所忌 → 两边分写，不能平均为吉 | 一方喜金不等于另一方应该承担某种现实角色 | 《滴天髓阐微·衰旺》《岁运》的喜忌相对性；本skill跨盘归纳 |
| H09-08 现实主题 | 上述差异+本人主动提供的相处情境 → 可提出沟通、节奏、责任分配的开放问题 | 不反推性取向、暴力、忠贞、第三方隐私；现实意愿与实际行为优先 | 本skill R8、R10；非古籍预测规则 |

**取舍与证据缺口**：所读三部古籍主要是单盘，没有可核的现代双人合盘检验。本skill只借用其中的单盘关系原则做对照，不伪称古籍已规定了一整套跨盘算法。五合、互为十神等是可重算事实；“相处好坏”没有由这些事实推出的验证链，留在v0.2待验。

## 三、worked examples：均为人工教学配对

两组都取公版古籍单盘，**没有史料说他们是伴侣、合作人或同时代**。用于核对规则如何执行，不是历史合婚案例，也不是匹配测试。比较事实保存在[方法事实包](../examples/古籍方法自测-事实包.json)。

### 例一：土旺与润下——相合不能替代各自用神

A **戊辰 戊午 戊申 己未**，《滴天髓阐微·衰旺》；B **壬子 辛亥 癸丑 壬子**，《形象》。

1. 先各自定结构：A偏强厚土取金泄；B原书润下，木为泄水出口。不是一土一水便先判互补。
2. compare核A看B日干癸为正财，B看A戊为正官；戊癸五合是事实，但跨盘不得据此把双方日主改成火。
3. 跨盘午子冲等照列；两盘各自喜忌不同，不能统一说冲使两人都不好。A想借水润也须先有能作用的水，B原评无食伤之化（亥藏甲仍存在，见04校核），火财直入的判断须保留此条件。
4. 合、冲、寒暖只能形成沟通话题；不能说B替A补水、A替B补土于是天生匹配。
5. 都无可核年代，H09-12输出“共同时间窗口未核”；不把各自同名运硬拼。

### 例二：日柱天克地冲如何写

A **癸卯 乙丑 庚申 丁丑**，《滴天髓阐微·夫妻》；B **癸卯 乙卯 甲寅 乙亥**，《从象》。

1. A庚日寒金，丁暖、乙财引通；B甲日比劫印绶极旺，原著从旺。各自需求独立，不能金克木就跳过两盘分析。
2. 程序给日柱庚申—甲寅：甲庚冲及干相克、寅申六冲，符合本项目天克地冲候选。A看甲为偏财，B看庚为七杀，两个方向不改名。
3. B从旺路线不喜有力金克，故传统符号上这组差异更需说明；A乙财通关的需求又不能直接等于B现实愿意配合。
4. 可写：“两盘日柱有干克支冲，在传统模型里差异取象较显；实际相处需要询问双方如何协商节奏与决定。”不可写相克、克夫、必散，也不给分手建议。
5. 没有双方现实关系及时间轴，停在结构对照，不判是否适合结婚。
