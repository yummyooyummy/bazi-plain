# 示例报告（短版）：戊辰 戊午 戊申 己未

[返回 README](../README.md)

> 这份短版按[报告模板](../references/12-报告模板.md)的栏目排列，内容全部来自公版古籍和程序查表结果。
>
> 命例出自任铁樵《滴天髓阐微·衰旺》，**不对应任何现代真人**。古籍只给了四柱和原文叙述，没有出生日期和地点，所以很多栏只能写“资料不足”。出生信息和现实资料齐全时，这些栏可以按程序算出的大运流年展开；缺什么，仍然要明确写出来。

## 一句话认识这个盘

**像堆得很厚的一片土地，关键是有没有能持续疏泄的出口。** 这是学习用的比喻，不代表任何人的真实性格。（把握：低）

## 更像哪一种

**偏强的厚土，主取金来疏泄，不按从强论。**（把握：中）

- 午月火旺生土，辰、未是土根，天干戊、己成片，所以偏强。这个判断看的是当令、根气和帮扶，不是数土字。
- 从强要求盘里完全没有财官之气。这个盘的辰藏乙、癸，申藏壬，未藏乙，条件不满足。
- 金在申有根，是可以用的出口。原书也说其用在金。
- 没有第二种仍然说得通的读法，所以不算百分比。

## 你需要什么、怕什么

**先保住金这个出口，再看金和水能不能接上；木的作用要看条件。**（把握：中）

| 判断线 | 结论 | 限制 |
| --- | --- | --- |
| 格局 | 戊午按阳刃入口。没有官杀透出来制刃，也没有丙透、寅午戌成局，不能算化刃为印 | 不能因为午里藏丁就直接说是印格 |
| 病药扶抑 | 土太重，以申中庚金疏泄为主路 | 木能不能制土要看依托，不一概说木好或木坏 |
| 调候 | 查《穷通宝鉴》戊土午月：先壬，次甲 | 盘里有申藏壬，但缺明水不等于见水就好 |

### 为什么土这么多，还说“需要”别的

下面是程序查表后逐字数出来的：

| 五行 | 明字（8 个字里） | 藏干（另列，不和明字相加） |
| --- | --- | --- |
| 木 | 无，0 个 | 年支藏乙、时支藏乙，2 次 |
| 火 | 月支午，1 个 | 月支藏丁、时支藏丁，2 次 |
| 土 | 戊、辰、戊、戊、己、未，6 个 | 年支藏戊、月支藏己、日支藏戊、时支藏己，4 次 |
| 金 | 日支申，1 个 | 日支藏庚，1 次 |
| 水 | 无，0 个 | 年支藏癸、日支藏壬，2 次 |

字多不等于需要更多，字少也不等于缺什么就补什么。这个盘的问题是土太堵，所以要的是“疏泄”这个作用，金正好能做到。

## 事业

**能讨论的是“产出、表达、把资源变现”的条件，推不出具体行业或职位。** 金是食神，作为出口是结构上的结论，“适合做哪一行”从这个古例里得不出来。（把握：低）

## 财运

**一句话：财藏在地支里，能不能用上，要看金能不能把土的力量转出去、再生出水来。**

- **钱从哪里来：** 结构上的主路是“土 → 金（食神）→ 水（财）”，也就是靠产出和表达带来资源。这只是结构候选，现实收入未知。（把握：中）
- **财运等级：** 原局不给单一等级，要看运：金水接得上的阶段为“好”，厚土压住水的阶段为“要注意”，见下表。（把握：中）
- **存不存得住：** 壬、癸两个财都藏在地支，重土容易把水压住。财星透出来的年份，如果出口还是堵的，不能只因为见财就说有钱。（把握：中）
- **每个大运阶段：** 运柱来自原文，没有公历区间。

  | 文献运 | 财运等级 | 理由与限制 |
  | --- | --- | --- |
  | 庚申、辛酉 | 好（把握：中） | 金透有根，疏泄路径最直接，与原书叙述同向。不代表发财金额 |
  | 壬戌 | 要注意（把握：低） | 壬财透出，但戌加重燥土，又与辰相冲，财路有阻。不能因为财透就判顺 |
  | 癸亥、甲子 | 未评 | 水木来了能不能润土、有没有金源，条件没核清，不批量判好坏 |

- **近几年逐年：** 资料不足。古籍没有出生年份，无法对应公历流年。原文在辛酉运里提到辛丑年：辛金透出、丑里藏辛，金得到帮扶，和只看“丑未冲”就判坏不一样。（把握：中）
- **建议：** 这是学习用例，不给理财建议。学习时请注意，“财在藏干”和“财已经能用”是两件事。

## 感情与婚姻

**一句话：古籍例没有任何现实感情资料，只能讲结构，不编故事。**

- **另一半是什么样的人：** 资料不足。日支（伴侣宫）是申，藏庚、壬、戊；古法里男命以财为妻，这里只作为一栏符号记录，不推出伴侣的样貌、性格或人数。（把握：低）
- **相处模式和摩擦点：** 资料不足。伴侣宫被冲合触动的年份可以列为“关系议题”，但不能推出结婚或离婚。
- **已对上的事：** 尚未核对，古籍没有记载。
- **接下来的重点年份：** 没有公历年份，不给。
- **建议：** 学习时请记住，财星有两个不等于有两段婚姻。

## 子女与家人

食神金有根，不等于生育能力或孩子情况。不推断数量、性别或父母的情况。（把握：低）

## 健康保养

“土重”“燥”只是古书里的五行用语，不能据此判断身体状况。这里只写作息规律、饮食均衡、适量活动这类一般保养方向，**不是诊断**，也不从五行多少推出任何疾病。

## 还不确定的地方

1. 只有四柱，出生排盘、大运区间都无法核对，所以止步于方法学习。
2. 把同样的方法用到新盘时，要问的是“根和出口能不能成立”，不能拿古书已经写好的经历回头给自己加分。
3. 木制刃和金泄秀是两条有条件的路线，本例采用原书的金为主路，没有把木一概删掉。
