# 使用说明

[返回 README](../README.md)

## 平时怎么用

装好以后，在 Claude Code 里输入 `/bazi-plain`，在 Codex 里输入 `$bazi-plain`，然后说你想做什么。比如：

- “讲讲什么是调候。”这是纯知识问题，不会问你生日。
- “帮我看看这个八字：戊辰 戊午 戊申 己未。”只有四柱时，走古籍四柱模式，不推算大运。
- “我想看自己的八字。”走完整流程，下面细说。

## 完整流程

1. **确认信息。** 一次最多问 3 个问题：公历还是农历（农历要说清是否闰月）、出生时间有多准、出生城市；还会确认排大运用的性别参数。信息齐了先给你一张确认卡，你确认后才排盘。不需要姓名、证件号、收入或病史。
2. **程序排盘。** 运行 `scripts/paipan.py` 得到事实包（JSON）。程序报告信息不够（`input_required`）时，先停下来补信息。
3. **先看结构。** 先检查是不是从格，再定格局和喜忌；格局、病药扶抑、调候三条线分开写，有矛盾就并列，不用“综合来看”一笔带过。
4. **算倾向，必要时先问问题。** 有两种说得通的读法时，用 `scripts/score.py` 按固定规则算倾向，不让模型凭感觉报百分比：
   - 低于 60%：先给初判和最多 5 个校准问题，你答完再写完整报告；
   - 60%—79%：完整报告里两种说法并列；
   - 80% 及以上：直接写完整报告，问题放在末尾核对。
5. **写报告。** 按[报告模板](../references/12-报告模板.md)的顺序写。每一节先给一句话结论，财运写满六项，感情写满五项，资料不够的地方直接写缺什么。每条判断标“把握：高 / 中 / 低”，运势写“好 / 一般 / 要注意”。
6. **交付前核对。** 四柱和干支事实要与程序输出逐项相符，备选盘不能丢，结论里不能有旧式断语、疾病预测或改运推销。

不想回答校准问题也可以。报告会按条件写，受影响的部分标“待确认”，不会反复追问。

## 输入文件

个人输入请放在仓库**外面**，比如 `~/bazi-private/me.json`。字段说明见[排盘口径](../references/01-排盘口径.md)，常用的有：

| 字段 | 说明 |
| --- | --- |
| `date` | 公历 `YYYY-MM-DD`；如果是农历，再加 `"calendar":"lunar"` 和 `"is_leap_month": true/false` |
| `time` | `HH:MM`。时间只是大概的，加 `time_uncertainty_minutes`（单侧分钟数）；不知道时辰就先别填 |
| `sex` | `male` / `female`，只用来决定大运顺排还是逆排 |
| `city` | 中文城市名，从内置城市库查经纬度 |
| `longitude` + `timezone` | 不想用城市库，或者在海外出生，就直接给经度和 IANA 时区名（如 `Asia/Shanghai`、`America/New_York`） |
| `as_of` | 参考日期，决定“当前大运”和流年范围 |

运行：

```sh
.venv/bin/python scripts/paipan.py --input ~/bazi-private/me.json
```

默认输出不含原始生日。`--audit` 会把生日写进输出，只在本地排错时用，别把结果放进仓库。

只有古籍或别人给的四柱时：

```sh
.venv/bin/python scripts/paipan.py --chart 戊辰 戊午 戊申 己未
```

这个模式只查藏干、十神、关系，不反推生日，也不编大运。

## 为什么有时会给两张盘

### 晚子时（23:00—24:00）

晚上 11 点到 12 点之间出生，日柱算不算第二天，各家说法不同：

- **早晚子分开**（默认主盘）：日柱不换，时干借第二天；
- **23 点换日**：从 23 点起就算第二天。

两种都是正经流派，只是约定不同。程序总是两张都给，不会只给一张。

下面是为说明而构造的合成例，不指向特定人物：杭州，2000-01-01 23:30，女。

```sh
echo '{"date":"2000-01-01","time":"23:30","sex":"female","city":"杭州","as_of":"2026-11-09"}' \
  | .venv/bin/python scripts/paipan.py
```

输出里 `day_convention_comparison` 会列出：

- 早晚子分开：己卯 丙子 **戊午** 甲子
- 23 点换日：己卯 丙子 **己未** 甲子

`report_gate.must_confirm_zi_method` 为 `true`，意思是先用性格和已知经历校准选哪张，两张盘各自的十神、喜忌、财运和感情年份分开写，不能拼在一起。

### 离边界很近

出生时间离时辰交界、日界或节气交界不超过 30 分钟（正好 30 分钟也算），程序会把主盘和相邻盘都列在 `alternative_charts` 里。

- 节气时刻用的算法和另一个独立算法差异最大约一分钟，城市坐标也只是代表点，所以“差几十秒”的结果不能当真。
- 月柱没定下来时，不写完整报告；时辰没定下来时，子女、晚年这些靠时柱的部分先不写。

### 真太阳时

钟表时间会按经度和均时差换算成当地真太阳时，日柱和时柱用它来定。比如经度比 120° 少 1 度，就慢约 4 分钟。年柱和月柱则按真实时刻比较立春和十二节，不受这个换算影响。

## 其他小工具

| 脚本 | 用途 |
| --- | --- |
| `scripts/score.py --input 证据.json` | 按固定规则算两种读法的倾向分，输入格式见[校准问卷](../references/13-校准问卷.md) |
| `scripts/yearscan.py --input 事实包.json --start 2027 --end 2030` | 用已有事实包扫一段年份的流年关系，不重新读生日 |
| `scripts/relations.py 甲子 乙丑 ...` | 只列干支之间的合冲刑害 |
| `scripts/synastry.py A.json B.json` | 两张盘之间的干支关系事实；没有“合不合”的打分，也不预测感情走向 |

## 报告里那些词是什么意思

- **把握：高 / 中 / 低**：这条判断在方法内部有多稳，不是“会不会发生”的概率。
- **倾向 80% / 20%**：两种读法的规则内倾向分，同样不是概率。
- **好 / 一般 / 要注意**：某个大运或流年在这套方法里的相对评价。
- **待确认**：缺信息，或者你选择不回答对应的问题。

报告格式和每一栏该写什么，以[报告模板](../references/12-报告模板.md)为准；一个短版样例见[示例报告](example-report.md)。
