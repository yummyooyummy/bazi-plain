# 方法加厚版自测目录

更新日期：2026-11-09。只使用公版古籍四柱，不含现代真实人物生日、命盘或经历。

## 三个完整流程

1. [厚土取金](方法自测01-土旺用金.md)：强弱三项证据 → 严格从强排除 → 刃月入口 → 金泄与壬甲调候分层 → 文献运年 → 六亲、保养与未知项。
2. [润下与泄化](方法自测02-润下与泄化.md)：专旺与从强分开 → 保留丑己、亥甲 → 普通月劫与特殊润下分层 → 文献木运、火运条件 → 不能删掉反证。
3. [月劫接食财](方法自测03-月劫食财.md)：月令比劫别取财 → 己食为相 → 巳丑拱合与古书取用的化分开 → 丁巳调候冲突 → 丑未冲不直接推出婚变。

每篇均按既定报告栏位组织，并折叠记录12步执行。古籍缺出生日期，不假称完成真太阳时、起运年龄或当代流年排盘。没有两条仍有效主读法的个案不编倾向百分比；未拿未知现实结果填校准。

## 自测能说明什么

这是规则逐步应用、查表复核与反证检查。参照标签本就来自所读古籍，不是独立于教材的预测测试。没有声称完成多个不同模型的重复运行，也没有现实准确率数据。既有程序测试与文件不变校验见[验证记录](../VALIDATION.md)。

## 尚未定论

- 润下例的记录方式已由用户确认：保留评测标签“原局无食伤”，指未形成有效食伤泄化；亥藏甲伤官不删。程序、测试与标签值不改，具体泄化效力阈值仍待研究。
- 弱根、反神、合化是否真正得力，原书没有统一机械阈值；用反证和候选分支处理，不发明力量分数。
- 无可核真实双人古例时，09只作明确标注的人工配对。时间交集算法是说明流程，不是现有脚本新增功能。
